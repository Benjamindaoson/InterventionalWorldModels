# V2 independent confirmation preregistration

**Frozen before generation/evaluation.** The V1.1 test was viewed during development and is exploratory. This protocol defines a separate V2 confirmation family and must not be changed after its data are generated. Any later change creates a new protocol/version and leaves the first confirmation outcome intact.

## Data

Use `scripts/generate_v2_data.py` with 32 train scenes, 8 scenes in each of IID validation, IID test, physics OOD, geometry OOD, and confirmation; seven exact-snapshot branches per scene; 64 steps; 32×32 RGB. Training has 224 branches, exceeding V1.1's 140. Fixed mass/friction/box-size configurations are in `src/iwm/v2_data.py`. The confirmation configurations `(1.3 kg, 0.8, 0.06 m)` and `(0.9 kg, 0.25, 0.045 m)` do not occur in other families. Initial positions, velocities, contact heights and actions are generated by fixed deterministic rules. Dataset, source commit and file hashes must be preserved.

## Models and training

Run `scripts/run_v2_baselines.py` with seeds 17, 29, 43; 10 epochs; batch 14; AdamW 0.001; last checkpoint selected without looking at test; no early stopping within the 10 epochs. The eight arms are blind/conditioned/paired position-only; blind/conditioned/paired/shuffled-pair position+velocity; and velocity-aware RSSM. Deterministic width 96 and RSSM width 32 remain fixed. Identity and constant-initial-velocity are nonlearned baselines. All train/validation/test metrics use predicted xyz position, in m²; velocity error is separately recorded.

## Evaluation order and decisions

1. Finish all 24 neural runs and inspect IID validation, IID test, physics OOD and geometry OOD only. Do not alter models, hyperparameters, seeds, data generator or primary metric based on confirmation.
2. Run the confirmation evaluation **once** for all predeclared arms and both analytic baselines. Preserve every seed and scene.
3. Primary metric: mean same-scene final-step counterfactual delta MSE across nonzero actions, comparing `conditioned_vel` with `blind_vel`. Report paired scene bootstrap CI (2,000 draws, RNG 123) and all three seed outcomes. Secondary: 64-step free-running xyz MSE, action direction accuracy, horizon error, contact F1 and model-based planning. No seed exclusion.
4. A method benefit is supported only if primary delta error improves and no major OOD/planning regression appears. Otherwise record a negative result. Eight confirmation scenes are a pilot, not a definitive population claim.

**Status:** IMPLEMENTED protocol; confirmation NOT RUN at freeze time. Literature novelty and external replication remain separate gates.
