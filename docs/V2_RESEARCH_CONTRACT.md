# v2.0 研究与工程契约

项目名称：**Action-Conditioned Visuo-Tactile World Models for Contact-Rich Robotic Manipulation**（面向机器人接触操作的动作条件视觉—触觉世界模型）。唯一源代码仓库为 [Benjamindaoson/InterventionalWorldModels](https://github.com/Benjamindaoson/InterventionalWorldModels)。Windows 开发，GitHub 版本管理，授权后的 AutoDL 用于 GPU 实验。

## 证据分级

每项能力都标记为：已实现、已执行、已验证、未验证、失败、被阻塞、尚未开始。接口、配置、Mock、预训练权重下载或通过单元测试，不能替代真实训练。每份报告绑定代码提交、上游提交、数据修订与文件哈希、配置、种子、机器、CUDA/PyTorch、日志、参数更新证据、Checkpoint 哈希、独立评价和成本。

失败与负结果永久保留。先前配对监督未稳定获益的记录继续作为负结果；只有匹配对照可重新得出结论。不能宣称未发生的真机部署、论文发表或研究优势。

## 模型与数据边界

目标架构：`观测 → 表征编码器 → 潜在状态 → 动作条件预测器 → 未来状态/事件/观测`。输入契约包含 RGB/Depth、机器人本体状态、动作序列、时间戳/间隔，可选触觉与语言；首期语言不是依赖。输出契约包含未来潜状态、物理状态、接触/滑移事件、多步未来，可选视觉与触觉生成。

物理状态标签只用于训练监督、探针或离线评分。推理时学习模型只能读取当时可观测量与候选动作。Oracle 上界使用真值时必须单独标识。所有数据保留环境来源与单位；MuJoCo 与 SAPIEN/SAPIEN-IPC 快照不互换。模拟触觉必须标为模拟触觉。

数据按场景、物体、几何和物理参数分组，先冻结拆分及源哈希，再做归一化与训练。派生帧、同状态反事实分支和相邻轨迹必须跟随同一组，不能跨训练/测试泄漏。探针和校准器在与最终测试集分离的数据上拟合。每个对照固定数据、训练预算和能力边界，并记录偏离。

## 顺序门槛

| Gate | 必须交付的实测证据 | 进入下一关条件 |
| --- | --- | --- |
| G0 官方 LeWM Push-T | 固定上游、许可证、数据版本、完整训练日志、参数更新、Checkpoint、独立加载/评价、资源与差异报告 | 真实训练与评价经过审计；下载权重推理不算 |
| G1 表征 | LeWM / Frozen DINOv2，资源允许时 V-JEPA2；SIGReg 权重与无正则消融、冻结/训练 Encoder、独立物理 Probe、坍缩诊断 | 能说明保留与遗漏的物理信息 |
| G2 动作动态 | 同完整状态不同动作真实分支、重放一致性、无动作/拼接/FiLM 或 AdaLN、事件损失消融、动作敏感性与校准 | GPU 或批准的计算环境真实训练与独立测试 |
| G3 视觉触觉 | 核实 ManiSkill-ViTac2025 许可与接口、同步数据、视觉/触觉/动作消融、遮挡与物理参数测试 | 真实模型训练；仿真与真实传感器严格分开 |
| G4 生成未来 | 轻量 latent flow matching 或 diffusion、动作/无动作、事件辅助和时域消融、配对真实帧与物理一致性评价 | 真实生成式训练及 Checkpoint；简单重建不算 |
| G5 泛化规划 | 严格 OOD 分组、同状态反事实、候选动作/MPC 与随机及无模型对照、独立闭环、时延和成本 | 如实报告收益或无收益 |
| G6 统一评测 | 冻结模型与数据、多种子及区间、泄漏审计、完整来源、失败结果、图表与最终报告 | 全部报告引用真实工件，无空结果冒充结论 |

任一 Gate 未过时先诊断和修复，不跳过关键验收。替代数据或算法若改变研究问题、协议或费用，先形成可审阅方案。G0 之前不启动后续正式训练。

## 费用与外部资源边界

正式 AutoDL 训练之前：核实 SSH、GPU/CUDA/PyTorch、磁盘容量与持久性、数据位置、计费价格；根据一次有上限的计时试跑估算 GPU 小时和总费用，设停止上限，提交给用户批准。不得购买实例、启动计费长训练或删除云数据。当前建议路径 `/root/autodl-tmp/InterventionalWorldModels`、`/root/autodl-tmp/IWM-data`、`/root/autodl-tmp/IWM-runs` 仅在云端核实后才成为有效路径。

## 阶段记录

每个 Gate 以“实现→测试→真实训练→独立评价→审计→提交→推送→状态更新”为流程，项目本地保存机器、绝对路径、分支与 SHA、命令、测试、GPU/耗时/价格、配置、工件路径与哈希、真实指标、失败和下一关。任何未观测值填 `N/A` 或 `BLOCKED`，不得估写为实测。
