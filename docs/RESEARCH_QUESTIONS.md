# Falsifiable research questions

1. **Long horizon:** Does free-running position error increase with horizon relative to teacher forcing under identical actions? Report each horizon and independent seeds.
2. **Physical consistency:** Given an identical full physics snapshot, do action branches yield distinguishable, correctly ordered futures? Compare conditioned, blind, shuffled, paired and capacity-matched controls.
3. **Planning utility:** Does a world model improve realized action outcomes at fixed planner cost? An offline three-candidate branch selection check has run on two held-out scenes; closed-loop planning has not. Visual fidelity cannot answer this question.
